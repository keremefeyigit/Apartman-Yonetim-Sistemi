# SIYOS Katman / Teknoloji Önerileri

| Katman              | Teknoloji (Öneri)             | Rolü                                                                                             |
|---------------------|-------------------------------|--------------------------------------------------------------------------------------------------|
| Frontend (Arayüz)   | React.js / Vue.js             | Modern ve etkileşimli bir dashboard arayüzü geliştirir; rol bazlı sayfalar ve component sistemi sağlar. |
| Backend (API)       | Node.js + Express             | İş mantığını yönetir, veritabanı ile haberleşir, kimlik doğrulama ve raporlama uç noktalarını sunar. |
| Veritabanı (DB)     | PostgreSQL / MySQL            | Kullanıcı, talep, konum ve log verilerini güvenilir biçimde saklar, ilişkisel sorguları destekler. |
| Analiz (BI)         | Python (Pandas) + Mikroservis | Yönetici dashboard'u için ısı haritası ve performans gibi analitik metrikleri hesaplayıp API'ye aktarır. |
